### Featured Engineering Projects

#### [Hybrid Binance Crypto Market Pipeline](https://github.com/Cliffe16/Hybrid-Binance-Crypto-Market-Pipeline)

> Lambda architecture pipeline streaming 115,000+ data points across 3,700+ Binance pairs with zero data loss.

* **Stack & Flow**: Airflow $\\rightarrow$ PostgreSQL $\\rightarrow$ Debezium WAL CDC $\\rightarrow$ Kafka $\\rightarrow$ PySpark Structured Streaming (30s micro-batches) $\\rightarrow$ Cassandra $\\rightarrow$ FastAPI & Grafana.

#### [NBA Analytics Pipeline](https://github.com/Cliffe16/NBA-Analytics-Pipeline)

> Automated daily ELT pipeline ingesting NBA game and player stats into Google Cloud Storage and BigQuery.

* **Stack & Flow**: Python API Extraction $\\rightarrow$ GCS Parquet $\\rightarrow$ BigQuery Kimball Star Schema (SCD Type 2) $\\rightarrow$ Airflow (Astronomer Cosmos) & dbt Core + MetricFlow $\\rightarrow$ FastAPI.

#### [Agricultural Commodity Engine on Microsoft Fabric](https://github.com/Cliffe16/fabric-agri-commodity-engine-pipelines)

> Hybrid real-time and batch Lakehouse combining FAOSTAT crop yield datasets with live Yahoo Finance commodity feeds.

* **Stack & Flow**: GitHub Actions & Azure EventHub $\\rightarrow$ Fabric Eventstream & KQL Eventhouse (5m tumbling windows + Data Activator alerts) alongside PySpark Medallion tables with 10% DLQ quarantine and T-SQL RLS.
